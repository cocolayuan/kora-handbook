# 可乐乐 Kora · 素材与风格手册

**[点击在线翻页，无需下载](https://cocolayuan.github.io/kora-handbook/)**

使用 [OpenZine](https://github.com/JosssphZhou/openzine) 制作的 24 页手册，展示个人拼贴审美、配色、素材处理、分镜与工作流。桌面双页、手机竖屏单页，支持点击、拖动与键盘左右键。

本仓库仅发布已获确认的手册预览。原始照片、视频、完整素材备份与剪辑 Skill 仍在私密仓库中。212 条预览记录包含原图、派生切片和同源素材，不代表 212 张独立照片。

## 文件

`index.html` 是约 10.6 MiB 的独立网页，图片和翻页程序均已内嵌。GitHub Pages 从 `main` 根目录发布。更新手册时替换此文件并推送即可。

## 来源

保留 OpenZine / Paper 来源链接与相关声明，见本仓库的三份许可文件；OpenZine 的不同部分沿用各自条款。个人照片及第三方图片不因本手册公开展示而获得开放再分发许可。
